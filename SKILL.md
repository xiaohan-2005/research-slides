# Research Slides Skill

## Purpose

Convert research materials into structured, visually coherent presentations.

Input:
- PDF papers
- Research notes
- Dataset analysis
- Markdown documents

Output:
- Slide structure
- Visual plan
- Citation-aware presentation content

## Core Workflow

### 1. Understand
Extract:
- Research question
- Motivation
- Methods
- Results
- Limitations
- Conclusions

### 2. Verify
Never invent:
- Numbers
- Citations
- Experimental results
- Claims

Every important statement should have a source.

### 3. Design
Choose a style before generating slides:

- Scientific Minimal
- Research Dark
- Editorial Academic
- Data Story

### 4. Build
Prioritize:
- Clear narrative
- Visual explanation
- Figure reuse
- Equation readability
- Consistent layout

## Principles

### Show, Don't Tell
Prefer visual examples over vague descriptions.

### Research Integrity First
A beautiful slide is useless if the science is wrong.

### Progressive Disclosure
Keep this file as the entry point. Detailed rules live in separate documents.
