# Attention Is All You Need — Demo

## Goal

Convert a landmark NLP paper into a clear research presentation workflow.

## Source paper

Vaswani et al. (2017)

**Attention Is All You Need**

## Demo workflow

```text
Paper PDF
   ↓
Research structure extraction
   ↓
Slide narrative design
   ↓
Visual explanation
   ↓
Citation-aware presentation
```

## Planned outputs

```text
attention-is-all-you-need/
├── README.md
├── slide-outline.md
├── citations.md
├── visuals/
└── presentation.html
```

## Why this paper?

The Transformer paper is a good benchmark because it contains:

- a clear research question
- mathematical formulation
- architecture diagrams
- quantitative evaluation
- long-term scientific impact

This makes it suitable for testing whether an AI system can transform research material into an understandable scientific story.
