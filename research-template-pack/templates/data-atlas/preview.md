# Data Atlas Preview

## Metadata

- Slug: `data-atlas`
- Mood: analytical, structured, quantitative
- Tone: modern, evidence-forward, disciplined
- Best for: statistics, modeling, experiments, benchmarking, survey research, data-heavy technical reports
- Evidence focus: charts, uncertainty, comparisons, ablations, tables

## Visual Snapshot

A light analytical system built around direct labeling, rigorous comparison, and visible uncertainty. Clean white/stone canvas, strong numerical hierarchy, cool blue/green data marks, and amber reserved for caveats or meaningful contrasts.

## Preview Ingredients

- Palette: stone `#F5F6F3`, white `#FFFFFF`, ink `#17202A`, blue `#315E8A`, green `#2E7D64`, amber `#B36A2E`
- Typography: Manrope for display, IBM Plex Sans for body, IBM Plex Mono for metrics/labels
- Signature move: chart-first composition with large direct labels and compact methodological context
- Signature move: uncertainty and baseline information stay visible
- Avoid: KPI dashboards, decorative donut charts, unlabeled bars, rainbow palettes

## Preview Rules

- Create one real 1920×1080 title slide using actual project/paper content.
- Hint at the data language with a restrained plot or measured grid, not fake metrics.
- Do not show template names, option labels, filenames, or workflow metadata.
